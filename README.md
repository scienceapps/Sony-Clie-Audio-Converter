# Sony Clié Audio Converter
![sony clié](https://github.com/scienceapps/Sony-Clie-Audio-Converter/blob/main/clie.jpg?raw=true)

This web tool converts audio files (WAV, MP3, FLAC) into the exact format required for playback on Sony CLIÉ handheld devices.

 - Start application [here](https://scienceapps.github.io/Sony-Clie-Audio-Converter/sony-clie-converter.html).
 - Drag and drop audio files (FLAC, WAV, MP3) & select bitrate.
 - Click Convert, extract zip and copy output files to /PALM/Programs/MSAUDIO/.

Note : Bitrate 320 kbps deosn't work on palmOS 4.x devices like Sony Clié SJ33, NR70 or N770c
